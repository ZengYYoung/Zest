## 2026-10-13 — M001：本地 Git 项目登记

提交标题：`feat(projects): add local Git project registration`

### 目的

为导入模式建立可运行的基础：先确定正在管理哪个仓库、哪个版本，以及采集时工作区是否存在未提交修改。项目理解、代码检索和修复等功能以后基于此继续扩展。

### 本次实现

- 建立 Python 包与 CLI，当前运行只依赖 Python 3.11+ 和 Git。
- `project import` 检查本地 Git 仓库根路径，只读查询分支、HEAD、脏状态及暂存/未暂存/未跟踪项统计。
- 支持空仓库、分离 HEAD、Git worktree 和中文/空格路径；拒绝普通目录、文件、bare 仓库及仓库子目录。
- 使用本地 SQLite 保存项目登记，规范化路径用于去重；重复登记保留原项目 ID 和创建时间，更新采集结果。
- `project list/show` 读取持久化记录；错误使用非零退出码和 stderr JSON。
- 查询时移除继承的 Git 环境覆盖，禁用 fsmonitor 与可选 Git 写锁；新状态目录和数据库使用受限权限。
- 补充 README 运行说明、总体设计实现进度及 `.zest/` 忽略规则。
- 将此前撰写但未提交的总体设计文档一起纳入本次开发基线。

### 验证

执行：

```bash
python3 -m unittest discover -s tests -v
```

结果：**25 项通过**。本次验证环境为 macOS、Python 3.13.9、Git 2.54.0；尚未单独验证其他 Python 版本或操作系统。案例使用临时目录中的真实 Git 仓库，包含：

- 空仓库、正常提交、分离 HEAD、Git worktree。
- 同时存在暂存/未暂存/未跟踪修改，以及带换行符文件名的重命名。
- 重复登记、路径别名去重、跨进程读取和未知项目。
- 无效路径、不兼容数据库版本、数据库损坏及规范 JSON 错误。
- 继承 Git 环境无法重定向查询，fsmonitor 脚本不执行。
- 采集前后目标文件和 Git 索引字节保持一致。
- 采集过程中 HEAD 变化会被拒绝。

此结果验证的是项目登记模块，不代表已验证 Agent、RAG、修复、部署或生产回退。

### 当前限制

- 登记是元数据采集，不复制代码，也不是未提交文件的不可变快照。
- `list/show` 展示上次采集结果；需再次 `import` 才会刷新。
- 未跟踪目录可能按一项统计，不等于文件总数。
- SQLite 状态绑定指定状态目录；完整用户权限、历史快照和生产部署尚未实现。
- 第一模块不接入 LangChain/LangGraph/MCP 或模型 API；这些能力待相应功能确定后接入。

### 下一项建议

只读项目概览：在已登记仓库中识别少量可验证的项目入口、依赖声明和文档位置。具体内容先讨论，不在本次提交内扩展。

## 2026-10-13 — M003：带版本来源的文件读取

提交标题：`feat(projects): add versioned file evidence reader`

### 目的

让后续检索和问答能够引用可核实的正文，而不是仅知道文件位置。读取固定版本，并精确标记片段，避免 HEAD 变化、换行差异或未提交修改使证据失去来源。

### 本次实现

- 增加 `project read <project-id> <relative-path>`，支持完整 commit ID 和 1 起始行号范围。
- 默认选定查询时的 HEAD；明确指定旧 commit 时可以读取历史内容。
- 按路径组件精确遍历 Git tree，用户路径不作为 Git 匹配模式，不跟随链接或进入子模块。
- 输出路径、commit、blob ID、实际行号、总行数、片段正文，以及文件与片段的 SHA-256。
- 每个文件限制 256 KiB、每次 200 行、路径 32 层。行号按 LF 计算，片段保留 CRLF 和末尾换行状态。
- 采用文件类型和路径范围限制，拒绝常见凭据、生成目录、二进制、非 UTF-8 和部分已识别凭据模式；错误不回显检测到的凭据值。
- 不自动执行、传输正文或刷新登记记录；更新 README、设计文档和本日志。

### 验证

```bash
python3 -m unittest discover -s tests -v
```

结果：**65 项通过（原有 43 项 + M003 22 项）**。验证环境为 macOS、Python 3.13.9、Git 2.54.0。

新增案例覆盖：

- 行号、文件和片段哈希、证据 ID、200 行窗口及继续读取。
- 空文件、空行、CRLF、无末尾换行和 Unicode 段落分隔符。
- 历史版本、读取中 HEAD 改变、暂存/工作区内容被排除。
- 无效范围、超限文件、非 UTF-8、二进制及不允许的 commit 参数。
- 路径越界、链接、常见凭据目录、带空格/中文/匹配字符的精确路径。
- 请求片段之外出现已识别凭据也拒绝整次读取，错误不回显凭据。
- 缺失/未跟踪文件不回退读取工作区；工作区、索引和登记记录保持不变。

### 当前限制

- 只读已提交的 UTF-8 文本，不读取未提交代码，也不支持子模块正文。
- 路径和凭据模式限制不能识别所有敏感信息，尚未接入模型传输或通用脱敏。
- 不构建索引，不回答自然语言问题，不执行代码或修复。

### 下一项建议

允许文件范围内的关键词定位：返回匹配行及版本来源，为后续 RAG/项目问答提供基础检索能力。
