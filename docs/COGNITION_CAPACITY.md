# 首轮认知的资料与报告容量

日期：2026-10-15；模块：M040。用户确认本轮扩大包内阅读、目录展示和报告容量；模型调用次数、调查轮次及字符扩展规则沿用现有约定。

## 来源按实际范围校验

规划 overview/tasks 的 source_ids 不再额外限制为 6/8 个。每项至少一个，必须唯一、存在于本次实际展示给规划模型的 material_catalog；不能借此引用包外或未展示的身份。调查 Agent 仍可自主查找批准包内的其他文件。

报告 citations 不再额外限制为两条，仍须唯一、来自该任务实际 read 得到的非空原文。任务数量、六部分覆盖、依赖无环、事实/推测分类和独立核对继续校验。列表错误现在包含字段路径、实际数量及允许范围，非法/重复引用也说明字段路径。

所有固定格式输出仍使用有 Field 描述的 Pydantic 类型，经 model.with_structured_output 生成；动态目录与证据身份由业务校验核对，不依赖模型遵守描述。

## 本轮容量

| 项目 | 原值 | 当前值 |
| --- | --- | --- |
| 规划目录 | 60 文件 / 5000 字符 | 16000 字符，不另设文件数上限 |
| 规划起始文档 | 8 份 / 14000 字符 | 20000 字符，不另设份数上限 |
| 单次原文读取 | 1200 字符、最多 200 行，默认 80 行 | 3000 字符、最多 400 行，默认 120 行 |
| 文件清单单页 | 15 个 | 50 个，可继续翻页 |
| 词法检索 | 2000 块、6 个位置 | 8000 块、12 个位置 |
| Python 符号 | 前 100 个文件、10 个结果 | 所有包内文件、30 个结果 |
| 单任务报告 | 3 条发现、8 项未知、4 项扩包需求 | M044 起约 6 条发现为软建议、不按条数拒收；16 项未知；M046 起包内/包外资料需求合计 8 项 |
| 保留报告轮的输出 | 4096 token | 8192 token，其余认知请求仍为 4096 |
| 证据上下文提前报告预警 | 18000 字符 | 22000 字符 |

读取保持完整物理行、版本/文件哈希、行号与 more_after，不为凑预算截半行。规划额外说明目录覆盖及起始文档纳入数量，不能把预读窗口当成文件全文。报告及核对保留唯一原文表，持久记录不删证据。

M044 取消发现条数的硬上限，字段描述、工作指令与接收器同步；八条等合理数量不再使整份报告失败。完整响应 32000 字符的既有保护显式写入 POLICY，字符/token/调用预算和逐条引用/语义核对继续有效，不自动接受无依据的发现。详见 [报告接收](COGNITION_REPORT_RECEIPT.md)。

核对四条发现组成的完整请求若在外发前超过 48000 字符，会减小批次重新组织；无法放入单条时保留缺口。只拆分确定尚未发送的候选，不重发已收到、结果未知或等待字符批准的请求。32001–48000 字符仍暂停等待本次完整请求批准。

## 规模提示与授权

资料包达到 200 个来源、摸底遍历未完成或规划目录未能全展示时，预览明确提示先讨论按模块调查，或确认仅批准当前展示的固定资料包。终端需主动勾选范围确认；Escape 不作决定，Web 继续只读。200 是提示阈值，不是新增拒绝线；已有摸底仍有 200 文件尝试、4 MiB、时间/树预算，不能由部分摸底推断项目总规模。

本轮不调整 32 次模型请求、初始 4 / 总计 6 任务、每任务 4 轮、最多两个并行、1800 秒、完整包 16 MiB，以及默认 32000 / 单次批准最高 48000 字符规则。包外资料、执行测试、修改与发布各自授权。

POLICY、指令和 schema 均随完整包冻结。历史包与响应保留，变化后的契约需要新包和新的明确批准，不能沿用 M039 的许可。

## 验证边界

M039 保存的真实规划响应在原样保留的情况下，通过当前类型及业务规则的纯本地回放：原失败位置的 7 个与 10 个来源均有效且唯一。原始资料/结果冻结清单与数据库未变，没有调用模型、恢复旧 run 或改写评分。M039 仍是失败的一次真实验收。

离线测试覆盖大量来源、重复/包外身份拒绝、原文窗口和续读、包尾符号检索、扩大报告、核对拆批和大包预览确认；真实 LangChain/HTTP MockTransport 核对输出参数。前端测试与构建另行通过。

随后经独立批准完成一次真实验收：报告轮实际调用、5 条自动核对事实形成，但关键覆盖 1/10、核心 0/3、流程 0/6，仍未通过；没有触发字符扩展，未知请求不重发。具体线上缺口见 [M041 结果记录](COGNITION_ACCEPTANCE_M040.md)。
