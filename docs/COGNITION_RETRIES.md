# 已收到格式失败后的有限补试

M052，2026-10-15。用户选择用有限重试容纳已观察到的模型/接口非稳定结构化输出，本轮不继续追究供应商内部原因。生产提示词、Pydantic Schema 和 strict 接收边界不因重试放宽，也不证明模型问题的根因或线上成功率。

## 适用范围与授权

仅覆盖认知工作流的规划、调查、报告、原文复核四类阶段；问答、修改建议和显式单次诊断仍按各自现有执行入口处理。DeepSeekModel/SDK 的 max_retries 继续为 0，所有固定格式返回继续使用 with_structured_output。

新包的 POLICY 包含 max_format_retries=1：每个逻辑请求最多首次调用加一次补试。补试是新的付费模型调用，必须包含在已批准的总调用/时间预算内，32 次总预算不增加。每次发送前再次核对版本知识、完整包、目标、指令、schema、完整 HTTP 请求及预算。补试与首次请求逐字相同，不增补失败响应或修改指令，不扩充已批准资料。

新增策略改变包身份，旧审批包不能按新策略执行。历史失败及旧的一次外发批准不因此获得重发权限；本开发模块没有新增真实模型请求或 LangSmith 上传。

## 允许与停止条件

只有完整供应商响应已收到、安全原始 provider_response 已保留且适配器错误为 invalid_structured_output 时，才允许进入补试。这包括原生 arguments 不是 JSON、缺字段、类型或封闭对象不符等结构错误。

以下情况不触发补试：超时/断连/结果未知、鉴权或 HTTP 错误、敏感/超大响应、完整请求变化、引用无效、包外资料、报告语义不成立或业务校验拒绝。结构正确但事实错误不能靠这条机制重新生成。第二次仍无效则该逻辑请求停止并保存两次收据。M087新批准包仅对原文核对批次隔离此类已知格式失败，继续其他批次、以partial保留可用成果；未知和其他错误仍停止。详见[核对批次失败隔离](COGNITION_REVIEW_BATCH_ISOLATION.md)。

## 持久状态与恢复

原 cognition_calls 继续表示逻辑请求；新增可选 cognition_call_attempts 保存每次 attempt 的状态、收据、错误及时间。最近收据仍供旧读取方式访问，首次失败永久保留在 attempts 中。旧数据库只读时不要求新表，写入时增建表，不重写旧记录。

```text
首次 pending → 已收到格式失败 → 原收据与 retry_ready 一起提交
                                        ↓ 再核对权限/预算，原子预占第二次
                                  第二次 pending
                                   ↙         ↘
                            completed       invalid / uncertain
                              复用          停止、不再补试
```

首次收据提交前中断：仍是 pending，拒绝重发。首次失败与 retry_ready 已提交后中断：用户显式 recover 可继续尚未申请的补试。第二次已预占为 pending 后中断：结果未知，不重发，即使实际网络可能尚未启动。成功结果已保存后节点中断：复用成功结果，不增加调用。总次数和工作流时间每次重新检查，预算用完时保留失败收据并停止。

状态、逐次收据、请求身份可用 `zest cognition show <run-id> --calls` 查看。CLI/终端显示补试规则及实际的“格式失败已保存 / 第 2 次请求已开始”事件，call_count 包含所有已预占尝试。Web 的总预算及事件仍只读展示；未扩展 Web 写入权限。

## 验证与收尾

tests/test_cognition_retries.py 使用真实 LangChain/SDK + HTTP MockTransport，覆盖原生 JSON/类型失败后成功、连续失败停止、超时、敏感与超大输出、引用错误不重试、次数/时间预算、两个中断位置、缓存复用、旧策略及请求身份变化。

另在固定公开样本 3a9e0c0 的新临时认知包中，用 M049 已保存的无效原生 body 与 M051 已保存的有效 body 顺序回放；不调用模型，不上传 LangSmith，不重算线上质量。该回放只证明补试持久化链路可处理历史两种响应，不证明下次真实重试必然成功。

供应商为何产生无效 JSON 的内部原因仍未知。本问题按上述有限补试机制收尾，后续优先推进增量认知；不继续自动试跑或更改输出契约。
