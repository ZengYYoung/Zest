# 认知报告中的资料需求分类

日期：2026-10-15；模块：M046。修正 M045 定向验收中五项包内未读资料被列为包外需求的问题，不新增读取、调用或批准权限。

## 批准目录与已读证据

规划阶段仍使用有容量提示的导航目录。每个任务的 material_catalog 则传递固定批准包的完整精简目录，仅含 ID 和路径；报告收束时保留它，不再缩成已读来源清单。目录没有文件正文，不能充当 R 证据。

read_source_ids 单独列出该任务成功读取过的来源，包括空文件/空窗口观察。它只表示至少读过一个窗口，不代表读完整个文件；实际内容、行段、more_after 和空观察仍看工具结果。只有非空原文才有 R 编号。

完整目录计入实际请求字符数，不为控制大小悄悄删去授权身份或原文。原 32000/48000 字符暂停批准与超限收束规则继续生效；资料过大时保留缺口，另行商量拆分。

## 模型输出和本地分类

调查/报告继续使用 model.with_structured_output 和带 Field 描述的 Pydantic 模型。报告显式包含 status、findings、unknowns、material_requests；后者为具名 MaterialRequest 列表，每项字段全部必填：

| 字段 | 含义 |
| --- | --- |
| source_id | 包内填写固定目录中的 ID；包外填写空字符串，不使用 null |
| path | 包内精确相对路径；包外填写具体文件或资料位置 |
| reason | 需要回答的问题，或已读窗口还缺哪部分 |

包内待补读与包外需求合计沿用八项额度，不增加模型调用、工具动作或自动补查轮次。unknowns 仍说明未回答的问题；它不决定资料授权范围。

程序对照完整固定目录分类，模型不能自行授予或扩大权限：

- ID 与路径一致，或空 ID 的明确路径与目录精确匹配：归入 in_scope_requests。已成功读过窗口为 approved_read，其余为 approved_unread；两者都只是待补读需求。
- 空 ID 且具体位置不在目录中：归入 scope_requests，location=outside_package，提示包外资料须另行批准。这里只说明不在该包，不证明资料存在或可访问。
- 未知 ID、ID/路径不一致或缺少固定目录：该需求单独留痕于 rejected_material_requests，不误列为包外授权申请，不牵连丢弃有效发现。缺必填字段、错误类型和敏感输出仍按完整响应规则拒绝。

路径仅做 POSIX 词法规范化，不访问磁盘或解析符号链接；URI 保留原样。不会用文件名近似匹配自由文本，也不会读取请求指定的位置。实际工具仍只能使用批准包中的来源 ID。

原始安全收据、original_report 和原始请求位置保留。material_request_resolutions 记录原索引、程序解析的 ID/路径、原因和分类；派生的 in_scope_requests/scope_requests 不冒充模型原输出。任一需求未接收或仍有有效资料需求时为 partial。有效发现继续独立语义核对，资料需求不发布为共享事实。

CLI、终端与只读 Web 分别显示“包内待补读（尚未读取）”“包内待补读（已有读取窗口）”“包外资料需另行批准”和“资料需求未接收”。档案保留同样待办。旧 scope_requests 自由文本只显示为“历史资料需求（未分类）”，不猜测迁移、不改写旧记录。

## 验证与限制

离线任务图/MCP 回归覆盖报告收束仍可见未读来源、空读取与正文证据区分、三类需求分类、错误 ID/路径隔离、有效发现保留、原始索引/收据留存、无自动补读及 checkpoint 恢复不增加请求。原生 LangChain/HTTP MockTransport 验证包含 MaterialRequest 的实际 strict schema；错误/缺字段仍拒绝。

对 M045 保存响应进行明确标记的人工定位派生回放：把原五条自由文本与其具体包内路径配成新类型测试输入，得到 **五项包内待补读（一个已读窗口、四个未读），零项包外**，十条候选与编号保持原样。这个派生输入不是原模型响应；原始旧响应在新 schema 下仍被拒绝，不自动补字段或修复重发。

回放、完整请求编译与旧授权阻止检查均未访问模型服务；未发送的当前输入示例为 9795 字符，与旧冻结请求不同。旧包/参考/响应/数据库保持原样，历史完整认知质量分没有重评。当前契约变化会阻止旧批准执行，后续真实验收需要新冻结包与明确批准。

本模块不处理 unknowns 的全部语义一致性、不实现自动增量刷新或未知项自动调查；上述分类是否改善真实模型表达，仍需后续真实验收。M045 的一次真实结果与边界见 [定向验收记录](COGNITION_ACCEPTANCE_M044.md)。
