## 使用

本次前端已经构建、模型已配置。服务还在运行时，直接打开http://127.0.0.1:8000，无需再次测试模型或生成token。

需要以后重新启动时：

```bash
cd /Users/zengyy/code/AgentDev/project
uv run zest web serve --port 8000
```

页面中按顺序操作：

1. **项目概览 → 接入项目**：填入本机已有Git仓库根路径；已有项目直接从项目选择器切换。
2. **项目认知 → 准备项目认知**：本地采集完成后打开结果，审阅完整包、模型与预算，明确批准后台调查。查看六部分档案和未解决问题。
3. **项目对话**：输入“主要请求经过哪些模块？”等问题，按发送按钮或Cmd/Ctrl+Enter；先准备来源，再审阅并批准调用，结果附原文引用。
4. **修复 / 开发建议**：在输入框底部切换任务类型，展开文件范围，输入需求和明确路径；建议生成后去候选修改独立审阅批准，后续验证与源码选择分别批准。

“模型连接”用于查看本次测试，或在更换配置后准备新的单次测试；配置正常不必每次使用前重测。模型密钥只在本地`.env`填写。修改前端后执行`npm --prefix frontend run build`并刷新，修改后端后重启服务。
