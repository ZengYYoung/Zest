# 连续对话与 Web 界面（M113）

## 使用

前端已构建。若旧 Web 进程仍在运行，先在原终端按 Ctrl+C，再启动：

```bash
uv run zest web serve --port 8000
```

打开 `http://127.0.0.1:8000`。选择已接入的项目，或通过左上角加号填写项目根目录。
macOS 可在接入窗口点击“在 Finder 中选择文件夹”，系统文件夹窗口选中后自动填回本机路径，
再点击“接入并初始化”。取消保持原输入；仍支持手动粘贴路径。选择本身不读取项目正文、不初始化、不调用模型。
窗口在运行 Zest 服务的 Mac 上打开；其他系统或无图形桌面环境可手动填写路径。
目前接入已有 Git 项目；新建项目仍可用 CLI，不要求用户在主界面学习任务类型。
新接入项目会自动完成初始化，在主对话上方显示后台进度和完成摘要。
完整范围可按需查看，完成后可以直接提问。详见 [项目初始化](initialization.md)。
已发布的初始化在重新打开项目或刷新页面时不再作为常驻任务展示；本次访问中观察到的初始化完成
仍可简短汇报。历史初始化与知识缺口统一从“项目状态 → 初始化记录与知识缺口”展开查看。
关闭提示只保存本机浏览器的记录身份，不修改调查结果或把缺口标记为解决。

接入后立即显示等待状态、已等待时间及后台实际阶段：检查 Git、整理文档、建立索引、准备调查范围。
不显示估算百分比；关闭接入窗口可继续浏览，操作完成后自动切换到项目。
后台尚未启动时可启动原排队操作；回执丢失则核对原操作，不重复接入。

初始化与增量调查的长度扩展请求先显示任务用途、目标、模型和字符数，展开查看涉及文件及完整请求。
多项请求可逐项处理，也可一次处理当前已列出的一批；每个请求的哈希都要匹配，当前集合变化则整批拒绝。
该操作不授权后续新请求。批准一项后立即刷新剩余数量，总体仍在等待时也更新列表。
错误按操作显示，不将上一项调查错误带到新打开的项目接入窗口；导航与状态查看仍可用。

直接在输入框表达问题或需求，Enter 发送，Shift+Enter 换行。
输入框固定在工作区底部。上方的对话、初始化、更新进度和批准请求在同一区域滚动，
展开详情或加载较长内容不会推走输入框；恢复对话期间输入框也保持显示。
发送消息后，Zest 自动准备本轮问题、必要前文与对应版本的来源，交给已配置的模型回答，
不再逐轮点击“发送资料并回答”。等待时显示“正在结合项目资料回答”，完成后可直接追问。
完整来源、模型目标与对话上下文仍可按需展开检查。普通问答不依赖初始化自动批准开关。
旧版本遗留的未发送消息提供“继续回答”，复用原任务；已取消、已失败或结果不明的执行不会自动重发。

追问沿用同一对话，刷新后恢复最近选中的项目与对话。M137 将顶部项目下拉框改为左侧“项目 → 对话”列表：
点击项目选择并展开，点击当前项目可折叠；多个项目可以保持展开，当前项目加重、当前对话以浅灰背景高亮。
对话缩进排列，不再逐行重复聊天图标；长名称省略显示，悬停保留完整名称，项目同时提示根目录。
已访问项目的列表仅在当前页面内缓存，直接点击其他项目下的指定对话时优先打开该条，避免被该项目默认对话替换。
列表较长时独立滚动，不影响正文与输入框；左栏顶部“新对话”开始当前项目的独立话题，项目标题旁加号用于接入项目。
顶栏保留 Zest 标识、当前项目名称、项目状态与设置。
M138 项目行在悬停或键盘聚焦时显示删除按钮，触屏保持可见；确认窗口说明仅从当前 Zest 列表移除，
不删除磁盘源码、`.zest` 文档或历史记录。移除当前项目后切换到剩余项目，最后一个移除后显示接入空状态。
重新接入同一目录复用原身份与记录。删除动作通过 `project.remove` 持久操作回执执行，重复回执不再次移除重新接入的项目。
已有后台执行不会被取消，历史收据仍可按原身份定位；列表移除不是停止任务或撤销已授予权限的操作。
欢迎区完整显示“Zest”，说明文字为“你的专属私人项目管家”。
窄屏下点击左上角图标打开“项目与对话”，切换项目时保留列表以便选择对话，选中对话后自动关闭并恢复触发按钮焦点，也可按 Escape 关闭。
浏览器只保存项目、对话和待核对操作的 ID，不把对话正文写入 localStorage。

右上角“项目状态”查看 `.zest/docs/` 中的工作区文档，包含尚未提交的修改。
可点击文档目录或本项目内的文档链接，长文档按每次 200 行继续读取。
分页期间内容发生变化时提示重新打开，避免拼接两个版本的正文。
此处工作区阅读不改变模型读取固定 Git 版本的规则。
“项目状态 → 检查更新”通过有边框、底色与刷新图标的按钮手动检查一次，
检查期间显示“正在检查更新…”并禁用重复点击；打开、切换项目和 Zest 完成任务也会自动检查。
无变化不调用模型，空闲时不定时扫描；详见 [项目更新检查](maintenance.md)。
更新完成提示默认简短显示，完整变更按需展开。已结束的历史更新不在刷新或切换回来后反复弹出；
关闭状态按项目、端口和调查身份保存在浏览器。新的调查或需要处理的新状态仍可提示。

“设置”中填写 DeepSeek API Key 并保存，即可供后续对话使用，无需编辑 `.env` 或选择模型。
连接测试是可选项，保存后显示已配置、待实测；详见 [DeepSeek 配置](model-settings.md)。
旧任务和维护操作保留在按需展开的
历史工作记录中，不作为主界面的独立导航。页面无需登录、注册或随机访问 token。

## 实现与边界

- 左侧显示项目与所属对话，不引入项目概览、源码地图、独立评分等功能分组；核心仍是对话与两个辅助入口。
- `conversations.sqlite3`、对话锁和任务数据库保存于各自本地状态，不随 Git 共享。
- 每轮消息绑定独立消息 ID、固定任务 ID 和 Web 操作回执；重复身份读取既有记录，内容冲突拒绝。
- 对话任务继续复用现有问答、来源检查和批准执行，不新建一套浏览器模型客户端。
- M125 Web 发送消息本身表示允许本轮只读回答：后台自动匹配准备出的资料哈希，
  沿用 TaskRunner 的模型目标、证据有效性、结构契约检查与耐久 checkpoint。
  只作用于该对话/该消息绑定的 question 任务，不授权修复、修改、测试或发布。
  同一消息重复发送仅回读；读取/刷新/恢复对话不触发回答。未知执行不能由继续接口重放。
- 前文作为交流上下文进入本轮完整请求与批准哈希，不成为已确认知识、源码证据或执行授权。
- 先前引用的文件作为定位线索，在新一轮对应的 Git 版本重新读取；旧回答保留原观察版本。
- 对话记录长期保存；每轮模型上下文最多保留最近 12 轮、20000 字符，并明确标示截断。
- 读取、刷新、切换对话不调用模型；业务歧义通过交流澄清。当前仍是对话基础能力，
  不宣称已经完成自动需求判断的模型语义验收或自主开发、自动测试、提交、推送与部署。
- M115 首次初始化会生成初步项目理解和共享文档，完成后自动进入问答上下文。
  M116 通过明确事件检查本地 Git，有效新提交按已确认的策略增量维护，不重复初始化。

## 新增接口

| 接口/操作 | 用途 |
| --- | --- |
| `GET /api/projects/{id}/conversations` | 当前项目的本地对话摘要，按更新时间排序 |
| `GET /api/conversations/{id}?before={sequence}` | 恢复对话；默认最近 50 轮，可向前分页 |
| `conversation.create` | 通过既有 `POST /api/operations` 创建空对话，参数 `project_id` |
| `project.choose-directory` | 空参数，通过既有耐久操作打开 macOS 文件夹窗口；返回 `path` 或 `cancelled`，不接入项目 |
| `initialization.context-decide-many` / `maintenance.context-decide-many` | `project_id`、`approved`、`requests[{actor,sequence,sha256}]`，原子处理当前一批已保存扩展请求 |
| `conversation.send` | 同一操作内准备并回答，参数 `id`、`message_id`、`question`；`automatic_answer` 默认 true、严格布尔值；显式 false 保留仅准备语义 |
| `conversation.answer` | `id`、`message_id`；继续旧版本尚未发送的只读消息，校验对话/项目/问题/任务绑定；已执行或取消则仅回读 |
| `task.decide` | 通用任务显式批准或取消仍保留；日常问答无须单独调用 |
| `GET /api/projects/{id}/documents/workspace` | 只列工作区 `.zest/docs/` 文档，不列个人记录 |
| `GET /api/projects/{id}/documents/read` | 按 `path`、`start_line`、`end_line` 阅读工作区文档 |

项目状态不读取 `.zest/state/`、身份文件或符号链接；沿用文本类型、凭据与大小检查。

## 验证性质

单元与接口测试验证持久化、完整请求身份、重复/冲突/中断、跨版本重新读取、
历史分页、个人状态隔离与工作区文档读取；前端测试验证主入口、转义、上下文展示与构建。
浏览器联调使用临时订单项目和明确的离线替身，验证两轮交流、刷新恢复、
项目文档、长文档阅读、设置及当前窄窗口布局。替身回复不能证明真实模型会正确澄清业务。
本轮没有新增真实模型请求、GitHub 推送、真实项目运行或生产部署。
