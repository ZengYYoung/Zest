# Zest v1.0.1-beta.1

2026-10-29 · Testing release / 测试版

[English README](../../../README.md) · [中文 README](../../../README.zh-CN.md)

## English

This local single-user source release introduces **experimental hybrid retrieval for ordinary project Q&A**. It combines the existing TF-IDF and symbol search with Alibaba Cloud Model Studio `text-embedding-v4`, a local Qdrant vector index, RRF fusion, and optional `qwen3-rerank`. DeepSeek remains the answer model. Local embedded Qdrant and a loopback Qdrant server are supported.

Hybrid retrieval is opt-in. Building vectors sends committed source excerpts to the embedding service; questions and candidate excerpts are sent to the configured retrieval services and may incur charges. See the README Quickstart and [retrieval details](../../../docs/混合检索.md) for setup.

Each index is tied to a project, selected Git commit, embedding endpoint/model, and vector storage location. Answers reread source from the selected commit. Uncommitted changes are excluded. A missing or failed vector index falls back to lexical retrieval; rerank failure retains RRF. The Web conversation reports the active path. Missing current lexical indexes do not silently reuse older versions.

This is a test release: semantic index construction is manual, full rather than incremental, and currently CLI-only. A new version, model, embedding endpoint or vector storage location requires rebuilding. Investigation and document generation do not use hybrid retrieval. Tests cover local Qdrant and mocked model responses, and a temporary collection was used to check a Docker Qdrant server. The Alibaba Cloud services and retrieval quality, latency, and cost have not yet been evaluated end to end. No production readiness or retrieval quality improvement is claimed.

## 简体中文

本版为本机单人源码测试版，首次在**普通项目问答**中提供实验性混合检索：复用 TF-IDF 和符号定位，结合阿里云百炼 `text-embedding-v4`、本地 Qdrant 向量索引、RRF 融合和可选 `qwen3-rerank` 精排。最终回答仍使用 DeepSeek。Qdrant 支持进程内本地模式和本机服务。

混合检索默认关闭。构建向量会将已提交源码片段发送至向量化服务；问题和候选片段会发送至配置的检索服务，可能产生费用。配置方法见 README 的 Quickstart 和[混合检索说明](../../../docs/混合检索.md)。

索引绑定项目、选定 Git 提交、向量模型与接口以及向量存储位置；回答重新读取所选版本原文。未提交修改不纳入证据。向量索引缺失或失败时降级到词法检索，精排失败时保留 RRF；网页对话显示实际路径。当前版本缺少词法索引时，不会静默使用旧版本索引。

这是测试版：语义索引目前只能通过 CLI 手动全量构建，不支持增量构建或网页建索引。版本、模型、向量化接口或向量存储位置变化后需要重建。项目调查和文档生成尚未使用混合检索。测试覆盖本地 Qdrant 和模拟模型响应，并通过临时集合验证 Docker Qdrant 的写入和查询；尚未完成真实阿里云服务联调和检索质量、延迟、费用评测。本版不声称已生产就绪，也不预先断言检索效果一定提升。
