# Zest v0.1.0-alpha.1

2026-10-25 · First public Alpha release / 首个公开 Alpha 发行版

[English README](../../../README.md) · [中文 README](../../../README.zh-CN.md)

## English

Zest is a local project assistant for understanding Git repositories, answering questions with sources, and maintaining readable engineering documentation. This release captures the current single-user Web Alpha as a tagged source baseline.

### Included

- Conversation-first Web workspace with project folders, per-project conversation history, project status, and settings.
- DeepSeek API-key configuration in the browser; DeepSeek is the only supported provider and the Web preset is `deepseek-flash`.
- Project connection and initialization: `.zest/` resources, documentation import, committed-source indexing, investigation, and reviewed engineering pages.
- Local Git update checks and incremental knowledge/page maintenance, with stages, waiting indicators, page counts, and explicit outcomes.
- Bounded document-only continuation rounds, complete-evidence reuse, review-guided corrections, and recovery using saved receipts.
- Preservation of human-edited pages and indexes, with generated candidates and an explicit candidate-index viewer.
- Recoverable removal from the project list; reattachment preserves project identity and history.
- Shared `.zest/docs/` documents separated from local SQLite databases, conversations, credentials, and execution state.
- English and Simplified Chinese READMEs, Quickstart, storage/model explanations, and clearly labelled screenshots.

### Getting started

Clone this tag, install with `uv sync --locked --extra ai --extra web`, build the frontend with `npm --prefix frontend ci` and `npm --prefix frontend run build`, then run `uv run --locked --extra ai --extra web zest web serve --port 8000`. Open `http://127.0.0.1:8000`, save a DeepSeek key in Settings, and connect a local Git repository.

See the README for prerequisites, exact commands, data transmission, and the service/project state distinction. The source archive requires a frontend build; no desktop installer, hosted endpoint, or PyPI release is included.

### Validation and limits

A real local BlindBox document round published 5/5 pages using 27 of its 32 model calls while preserving the edited original index. This is one scoped workflow result, not a benchmark for overall model accuracy or large-project stability. Screenshots distinguish example conversation data from that real document-status result.

This is a prerelease for one local user. Native macOS use is the primary trial path. Other providers, native Windows validation, server deployment, PostgreSQL/multi-user collaboration, full branch/merge/deployment tracking, and a complete autonomous development pipeline remain outside this release. Calls to DeepSeek transmit relevant project context and incur provider charges; local saved keys are not encrypted.

Existing user resources are preserved. There is no automatic database consolidation or migration when changing `--state-dir`; earlier storage directories may still be referenced. Upgrading an existing checkout requires rebuilding the frontend and restarting the local service.

## 简体中文

Zest 是运行在本机的项目助手，用于理解 Git 仓库、结合来源回答问题，并持续维护可读的软件工程文档。本版将当前本机单人 Web Alpha 固定为可获取、可复现的源码版本。

### 本版包含

- 以连续对话为中心的 Web 工作区，提供项目文件夹、项目内对话历史、项目状态和设置。
- 在网页填写 DeepSeek API Key；当前仅支持 DeepSeek，Web 内置模型为 `deepseek-flash`。
- 项目接入与自动初始化：建立 `.zest/`、迁入文档、索引已提交源码、调查项目并生成经复核的工程页面。
- 本地 Git 检查与知识/页面增量维护，展示阶段、等待动画、页面计数及明确的结束状态。
- 有界的仅文档续写轮次、完整证据复用、依据复核意见修订及原回执恢复。
- 保留人工编辑过的页面与目录，生成候选并提供明确的新目录阅读入口。
- 可恢复的项目列表移除，重新接入沿用原身份与历史。
- `.zest/docs/` 共享文档与本地 SQLite、对话、密钥和运行记录分离。
- 中英文 README、Quickstart、存储与模型说明，以及注明来源的界面截图。

### 开始使用

克隆本标签，执行 `uv sync --locked --extra ai --extra web`，通过 `npm --prefix frontend ci` 和 `npm --prefix frontend run build` 构建前端，再运行 `uv run --locked --extra ai --extra web zest web serve --port 8000`。打开 `http://127.0.0.1:8000`，在设置中保存 DeepSeek 密钥，再接入本机 Git 仓库。

环境要求、完整命令、外发数据及服务/项目状态区别见 README。源码压缩包需要自行构建前端；本次不提供桌面安装器、托管地址或 PyPI 发布。

### 验证与边界

真实 BlindBox 本机文档轮次完成 5/5 页、使用 27/32 次模型调用，同时保留人工编辑的原目录。这只代表本次范围内流程跑通，不代表整体模型准确性或大型项目稳定性已验收。截图区分了示例对话与真实文档状态。

这是面向本机单人的预发行版，主要试用平台为 macOS。更多模型、原生 Windows 验收、服务器部署、PostgreSQL/多人协作、完整分支/合并/部署追踪和端到端自主开发不在本版范围内。DeepSeek 调用会外发相关项目上下文并产生费用；本地保存的密钥未加密。

现有用户资源保留。切换 `--state-dir` 不会自动合并或搬迁数据库，旧存储可能仍被引用。已有仓库升级后需要重新构建前端并重启本机服务。
